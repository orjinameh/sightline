## Problem

A building's signs are designed one at a time. A sign that reads well in a 3 m lobby is copied to the end of a 30 m corridor and becomes unreadable; or someone shortens the copy by hand, and the family stops agreeing with itself. The visitor who cannot find the exit, the toilet or the reception is the person who hurts. The facilities team that maintains the family is the person who keeps paying for it. The failure is not a bad sign; it is a **family that disagrees with itself** because every distance was solved separately.

## Solution

One Hyper Elements `Canvas` template for a sign family. A **directory** of destinations (name, long form, medium form, short form, arrow/pictogram) is the only input. The template renders the same destination at **3 m, 12 m and 30 m**; the distance chooses **which copy the sign carries** — not just the type size. The text is fitted to the sign's own size, and `image/fit` **refuses** copy that cannot fit the distance, naming the field and roughly how much to cut; nothing renders, so nothing is silently deleted. A pictogram or arrow is held to `field.image` limits, and `describe()` publishes the family's fields, formats, image regions and rules — the contract an agent fills.

## Must-have demo features

1. **The contract, visible.** `describe templates/sign-family.tsx --json` prints the three formats, every field (destination, long / medium / short copy, arrow, pictogram), each image's region and required pixels per format, and the rules. The README's first image is this view — the sponsor's own "how an agent sees a template" hero — not a pretty sign.
2. **The refusal that demands content.** A destination has no short form (or its short form is still the long form). The 30 m format refuses: `check` fires `image/fit` at that field, saying roughly how much to cut; **nothing renders**. The author writes a four-word short form; the strip re-renders. The refusal demands content; it does not destroy it.
3. **One directory, three distances, two buildings.** The same destination renders at 3 m (long form), 12 m (medium form) and 30 m (short form) from one template; a second building via `extendTheme` renders the family in a visibly different type and palette, proving it is a reusable template, not a one-off.

**Our answer.** The formula is not the product; the **family** is. ## Out of scope (explicit)

- **No ADA compliance claim at 30 m.** Table 703.5.5 is scoped to characters 40–120 in above the floor; beyond that, the ratio is a declared assumption. Never write "ADA compliant at 30 m".
- **No "legal maximum is six words".** The word budget is an opinion, labelled in `brand.ts`.
- **No print-ready claim.** These are **design proofs, not print files**; the README uses the exact sentence in §Feasibility. No bleed, no CMYK, no substrate, no fabrication.
- **No sign-shop calculator.** The product is the family + the copy-by-distance contract, not a distance-to-point-size calculator.
- **No silent deletion.** The template refuses; it never truncates copy.
- **No live data, no deployment, no chain, no paid asset.** The directory is a committed values file; fonts are OFL; the pictogram is a local SVG/PNG.
- **No `require.lint`.** Lint runs on Emails and Pages; on a Canvas it is `template/rule-unavailable`. Do not use it.
- **No four-artifact kit.** No email + page + PDF + social card set; the field's 34%/49% idiom is the thing this idea exists to avoid.

## Feasibility notes for the architect (primitives, not design)

All facts below are transcribed from the committed pack's raw docs (`raw/llms-full.txt`, `raw/GUIDE.md`, `raw/skill-brand-templates.md`; retrieved 2026-11-23) and re-verified by the judge (`11-judge.md` §0.5, §4.2). They are facts, not design.

**Package / runtime.** `@hyper-elements/react` **0.5.2** (MIT), `@hyper-elements/cli`, Node **24**. Render a Canvas with `renderImage()` from `@hyper-elements/react/image`; `render()` for HTML/text; `renderPdf()` for a Document fallback.

**Root and formats.** The sign family is a **`Canvas`**, whose `formats` are `{ width, height, scale }`. Chosen demo sizes (design choices, not standards): `near` 300×200 mm, `mid` 600×300 mm, `far` 900×300 mm. At 150 DPI that is `near` 1772×1181, `mid` 3543×1772, `far` 5315×1772 — large but renderable; verify the `far` render in the first hour. If it does not render/export, the `far` format becomes a **Document A3 1:1 PDF** and the demo survives on PDF alone.

**Template shape (exact keys).**

```tsx
export default template({
  id: "sightline.SignFamily",
  version: "1.0.0",
  label: "Wayfinding sign family",
  root: "Canvas",
  formats: {
    near: { width: 1772, height: 1181, scale: 1 },  // 3 m
    mid:  { width: 3543, height: 1772, scale: 1 },  // 12 m
    far:  { width: 5315, height: 1772, scale: 1 },  // 30 m
  },
  fields: {
    destination: prop.text({ label: "Destination", required: true, maxLength: 60 }),
    long:        prop.text({ label: "Long form (3 m)", required: true, maxLength: 120 }),
    medium:      prop.text({ label: "Medium form (12 m)", required: true, maxLength: 60 }),
    short:       prop.text({ label: "Short form (30 m)", required: false, maxLength: 30 }),
    arrow:       prop.choice(["left", "right", "up", "down", "none"], { label: "Arrow", default: "right" }),
    pictogram:   field.image({
      label: "Pictogram", required: true, fit: "contain",
      aspect: { min: 0.8, max: 1.2 }, minWidth: 512,
      accepts: ["svg", "png"], transparent: "required",
    }),
  },
  rules: {
    require: {
      core: ["canvas/overflow", "image/overflow", "image/glyph", "image/fit"],
    },
  },
  example: { /* every required field; a long/medium/short set; a real pictogram size */ },
  render(v, { format }) { /* LAYOUT[format] picks the copy and the type scale */ },
});
```

**The contract facts that make the demo real.**

- `formats` on a Canvas are `{ width, height, scale }`; `render` receives the format's name and must build that size, and the template checks it (`template/format`). **E3.**
- Fitted text is `fit={{ sizes, maxLines }}` on a `Heading` or `Text`, **only in a Canvas**. Text that fits at none of its sizes is `image/fit`, an error found when the image is measured with its fonts. **E3.** Use it for the destination and the copy.
- `image/fit` is the library's **measured** refusal — it is found when the image is measured with its fonts. **E3.** This is the money shot.
- `field.image` limits: `aspect {min,max}` → `template/asset-aspect`; `minWidth`/`minHeight` → `template/asset-pixels`; `accepts` → `template/asset-type`; `transparent` → `template/asset-alpha`; `fit:"contain"` → `template/asset-distorted` / `template/asset-cropped`. **E3.**
- `require.core` is a **closed set of seven codes**: `layout/overflow`, `layout/shrunk`, `document/overflow`, `canvas/overflow`, `image/overflow`, `image/glyph`, `image/fit`. There is **no custom predicate**; do not invent one. On a Canvas, use `canvas/overflow`, `image/overflow`, `image/glyph`, `image/fit`. **E3.**
- `require.lint` names lint ids and **checks Emails and Pages**; it does **not** run on a Canvas — a lint rule on a Canvas is `template/rule-unavailable`, thrown when the template is defined. Do not use it. **E3.**
- `describe()` returns each field's schema, each slot's allowed elements, each image's region **in each format** and the pixels it needs at that format's scale. **E3.** This is the first README image.
- `links.domains` / `images.domains` are rules; this sign family has no links and uses local images, so they are not needed. Do not claim them. **E3.**

**The copy-by-distance mechanism.** Do not expose "which copy" as a free field. Derive it from the format:

```ts
const COPY = { near: v.long, mid: v.medium, far: v.short || v.long } as const;
const LAYOUT = {
  near: { sizes: [64, 56, 48], maxLines: 2, art: { width: 420, height: 420 } },
  mid:  { sizes: [96, 84, 72], maxLines: 1, art: { width: 360, height: 360 } },
  far:  { sizes: [160, 140, 120], maxLines: 1, art: { width: 300, height: 300 } },
} as const;
```

The `far` format's `maxLines: 1` and large `sizes` are what make a long short-form fail `image/fit`. If the `short` field is empty, `far` falls back to `v.long` and refuses it — that is the demo's refusal. The author shortens the `short` field; the `far` sign re-renders. The `near` and `mid` signs keep their longer forms — the family agrees, and nothing was deleted.

**The legibility assumption.** Put the ratio in `brand.ts` as a declared, editable assumption, not a rule:

```ts
export const legibility = {
  // ADA 2010 Standards Table 703.5.5 within its scope (characters 40–120 in above the floor).
  // Beyond that scope this ratio is OUR assumption; replace it with your fabricator's.
  ratio: 0.0125, // character height / viewing distance, far-field assumption
  houseWordLimit: 6, // our house limit, not a legal maximum
};
```

The README cites the standard **within its scope** and the assumption **beyond it**, twice, exactly as the judge requires.

**CLI loop.**

```bash
npx hyper-elements describe templates/sign-family.tsx --json   # the contract
npx hyper-elements check designs/directory.tsx --require-template sightline.SignFamily --max-warnings 0
npx hyper-elements render designs/directory.tsx               # out/designs/directory.{near,mid,far}.png
```

`check` reads image files beside the design; `render` writes one output per format. `--require-template` fails any design the template did not check. **E3.**

**Brands and designs.** `extendTheme(base, overrides)` gives the second building its palette, fonts and pictogram set; two designs — a restrained editorial set and a high-contrast industrial set — prove reuse and carry `Design quality`. The second building must be visibly different (type + palette + grid), not a recolour.

**Fonts and assets.** `renderImage(element, { fonts, images })` takes local files; fonts must be **TTF / OTF / WOFF**, not WOFF2. Use OFL fonts committed to the repo; no remote images. A local SVG/PNG pictogram; no paid asset.

**The one build-time spike (first hour).** Render the `far` 900×300 mm Canvas at 150 DPI and export it. If it does not render/export, switch the `far` format to a **Document A3 1:1 PDF** and keep the demo on PDF. Do not promise a 30 m raster proof until this clears.

**The one external dependency to request on day 1:** none. The build is local, $0, no account, no key, no chain.
